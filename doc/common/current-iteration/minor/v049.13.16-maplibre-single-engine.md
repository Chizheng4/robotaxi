# v049.13.16 MapLibre 单引擎城市地图

## 状态

已完成。

## 根因

Leaflet 兼容地图只能提供部分二维查看与手绘表象，不能采集正式规划所需的底图物理单元。双引擎合同把“地图可见”误写成“规划能力可用”，并引入两套适配、更新、测试和故障切换成本。

## 执行结果

- [x] MapLibre 成为城市地理浏览和规划的唯一渲染与交互引擎。
- [x] 外部底图失败时继续使用 MapLibre 本地空样式，并保留城市边界、行政区和平台运营对象。
- [x] WebGL、MapLibre 加载或引擎创建失败时显示中文不可用状态，关闭城市规划入口并提供“切换网格仿真”。
- [x] 删除 Leaflet 运行资源、适配器、动态依赖、样式和双引擎切换状态。
- [x] 将双引擎验证重写为单引擎能力诚实性、fallback 和资源生命周期门禁。
- [x] 保持城市空间对象、业务服务、网格仿真、订单、Route 和模拟运行事实不变。

## 验收

- 自动检查、Bundle 一致性、真实浏览器桌面与手机布局、底图降级和业务运行态切换通过。
- Git、Tag、推送、EdgeOne 部署与正式域名版本分别记录，不以推送代替上线。
