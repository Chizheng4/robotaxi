# v049.13.9 导航字体所有权统一

## 目标

消除展开侧栏与收缩浮层因不同容器继承产生的字体差异，并减少短菜单浮层的无效留白。

## 结构

1. 导航注册表继续作为菜单名称、层级和页面关系的唯一来源。
2. `workspace-navigation-node` 是展开与收缩菜单共用的文字控件，直接拥有字体栈、字号、行高、普通字重、选中字重和文字颜色。
3. Ant Menu、浮层标题和浮层菜单项只负责布局、交互与状态，不得定义节点字体。
4. 每级浮层按本级内容计算宽度，并受统一最小、最大宽度令牌约束。

## 验收

- [x] 展开侧栏与收缩浮层使用同一共享文字节点
- [x] 容器不再维护独立字体规格
- [x] 普通、选中和祖先状态使用统一视觉令牌
- [x] 短菜单浮层减少无效留白
- [x] 结构门禁、完整提交前检查和真实页面验证通过
