# v049.13.8 导航字体与空间统一方案

## 目标

把展开侧栏和收缩级联浮层收敛为同一导航控件合同，使相同节点在不同状态下保持一致的字体、行高、字重、圆角和选中语义，同时显著减少无信息留白。

## 根因

- 导航树和当前状态已经统一，但展开侧栏由 Ant Menu 渲染，收缩浮层由自定义按钮渲染，节点内容与视觉令牌没有完全共享。
- 收缩浮层每级固定 `200px`，总宽度按级数相乘，短中文菜单也占用宽面板。
- 历史样式分别给根级、父级和浮层标题设置不同字重，层级被错误表达成字体差异。

## 统一合同

1. `navigationRegistry` 是导航结构唯一来源。
2. `NavigationNodeContent` 是展开与收缩状态的节点文字唯一结构。
3. 导航字号、行高、普通字重、选中字重和面板宽度边界由 `src/styles.css :root` 统一令牌定义。
4. 层级只通过缩进、级联面板、细分隔和箭头表达，不改变节点字体规格。
5. 每级浮层按自身最长可见标签计算宽度，并限制在统一最小、最大范围内。

## 验收

- 展开、收缩、一级叶子、二级和三级节点的计算字号、行高与普通字重一致。
- 当前选中项在展开和收缩状态使用一致的半强调字重和选中语义。
- 两级和三级级联浮层不出现固定宽度造成的大块空白，长中文仍完整显示。
- `1280 x 720`、`1440 x 900` 和窄屏状态无截断、重叠或页面级横向溢出。
- 导航结构、页面关系和业务逻辑不发生变化。
