# v049.13.12 城市地图统一交付合同

## 目标

让 MapLibre 与 Leaflet 只承担不同渲染能力，统一消费同一套城市空间视觉、缩放、交互和浮动信息合同，避免不同浏览器形成不同体验。

## 已完成

- [x] 建立城市空间共享表现合同，集中管理图层、缩放区间、颜色、透明度、状态变化和地图边界。
- [x] MapLibre 与 Leaflet 接入同一合同，保留各自渲染适配职责。
- [x] 城市范围和行政区支持统一浮动摘要，同时保持物理范围不可作为业务对象选中。
- [x] Leaflet 启用高像素密度瓦片并稳定地图尺寸更新。
- [x] 修复重叠区域之间移动时浮动信息过早消失的问题。
- [x] 更新双渲染、视觉反馈和空间规划自动验证。
- [x] 完成 Chrome 与内置浏览器真实页面加载、地图显示和区域浮动反馈验证。

## 边界

- 本版本不改变城市空间业务对象、生命周期或网格仿真闭环。
- 本版本不新增地图供应商、路由能力或线上部署配置。
