# v049.13.19 访问密码回车确认修复

## 事实与根因

- 正式站普通 Chrome 中，访问密码按钮可以提交，但密码输入框按 Enter 不触发认证。
- 现有密码输入框只依赖浏览器隐式表单提交；同页登录名称输入框已使用显式 Enter 处理。
- 现有自动化以底层键盘事件通过，但未证明普通 Chrome 真实密码控件的 Enter 反馈。

## 范围

- 密码输入框显式处理 Enter，复用既有 `submitVisitorPassword`。
- 过滤按键重复与输入法组合输入，保留按钮、loading、防重复、错误反馈和成功进入行为。
- 普通 Chrome 覆盖桌面与 390 手机的 Enter，并保留按钮路径验证。

## 非目标

- 不读取或修改 `visitAdminPassword`、`visitHashSecret`、`visitKv` 和访问数据。
- 不修改访问分析合同、业务对象、工作流规则或完整发布链。

## 验收

- [x] Enter 与按钮调用同一认证提交合同。
- [x] 输入法组合态和重复 Enter 不触发提交。
- [x] 390 手机 Enter 产生明确认证错误反馈，并可成功进入本地访问概览。
- [x] 桌面 Enter 可成功进入本地访问概览，按钮路径无回归。
- [x] Bundle、完整提交门禁与版本归档完成。
- [ ] 正式发布与公网动态门禁在提交、标签和推送后执行。
