# v049.13.21 Makers Production 环境注入发布修复

## 根因

- v049.13.20 固定发布指令直接上传本地预构建的 `dist/.edgeone`。
- Deployment 的静态资源和 Edge Functions 路由完整，但函数运行态未取得 Makers Production 文本环境变量。
- 官方 CLI 合同支持从包含函数目录和 `package.json` 的源目录启动自动构建；手工构建场景应部署该源目录，而非继续上传其 `.edgeone` 预构建子目录。

## 实现

- 保留 `dist/.edgeone` 作为发布前完整产物证明。
- 正式部署改为 `makers deploy dist`，由既有 `robotaxi-nochina` Production 项目上下文自动构建和注入环境配置。
- 公网 auth 使用故意无效诊断值，强制断言 `env_revision=rev-20260730-01` 且分类为 `ADMIN_PASSWORD_MISMATCH`。
- 完整源包与预构建产物均禁止 `.env` 文件；发布流程不读取、输出或传递 Secret。
- 既有 v049.2 墙钟性能门禁改为一次固定预热后五次独立采样，以中位数不超过 500ms 为主判定，并以单次不超过 650ms 防止严重退化；不改变被测代码、数据规模或业务断言。
- 有界 CPU profile 确认深拷贝占主要耗时；相关服务改用原生等价深拷贝并消除行政区新建几何的第二次无效拷贝，不引入跨调用缓存。重复场景必须深度等价、引用独立且单次修改不能污染后续结果。

## 非目标

- 不改变访问记录、KV、认证成功、token、按钮与 Enter 合同。
- 不修改任何业务字段、业务对象、公开内容或 EdgeOne 控制台配置。
- 不代替用户使用真实管理员密码完成最终人工验收。
