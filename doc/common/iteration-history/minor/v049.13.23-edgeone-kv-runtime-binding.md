# v049.13.23 EdgeOne KV 运行时绑定恢复

## 根因

- Production 项目已将 `visitKv` 正确绑定到 `robotaxi_visitre_cords`。
- EdgeOne 将 KV namespace 作为全局 binding 注入 Edge Functions；原实现误从 `context.env.visitKv` 读取，因此认证成功后的记录查询统一返回存储未配置。

## 修复

- 生产优先安全解析全局 `visitKv`，仅为本地专项保留 `context.env.visitKv` fallback。
- binding 统一验证 `get`、`put`、`list`、`delete` 四项能力。
- 多页读取以官方 `complete + cursor` 为主合同，对旧本地 mock 有界兼容 `list_complete`，并限制最多 5 个扫描页。
- 保留单次有界清理、30 天保留期、记录字段白名单、自动 QA 排除和认证合同。

## 非目标

- 不修改、迁移、清空或读取 Production KV 数据。
- 不修改密码、哈希 Secret、环境修订、访问页面交互或自动聚焦设计。
