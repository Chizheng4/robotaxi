# v049.13.17 EdgeOne 轻量访问概览

## 状态

已完成并发布；固定发布指令遗漏 Edge Functions 的缺陷由 v049.13.18 接续修复。

## 根因

CloudBase 会话模型和旧 EdgeOne 回退把访问分析扩展到心跳、时长、来源、地区与网络特征，超出“是否存在真实外部用户查看”的最小目标。两套生产路径同时存在也造成跨域失效、隐私语义分叉和维护成本。

## 执行结果

- [x] Robotaxi 只在正式域名通过“金星”登录后触发有效访问；登录页、失败登录、“访问”入口、preview、localhost 和自动 QA 排除。
- [x] EdgeOne KV 按站点、匿名访客和自然日幂等，重复访问只更新最近时间。
- [x] KV 字段收敛为七项白名单；删除会话开始、心跳、结束、精确时长以及 IP、地区、路径和来源语义。
- [x] 管理员概览支持三种站点范围、三种周期、最近记录、生成时间和父域设备排除。
- [x] 写入或查询时执行有界 30 天机会清理；EdgeOne 不可用不阻断普通登录。
- [x] 两份字段字典、EdgeOne 配置说明、xingbuild 最小共享接口和专项门禁同步。

## 外部门禁

- [x] EdgeOne 创建并绑定 `visitKv`。
- [x] EdgeOne 配置 `visitAdminPassword` 与至少 24 位 `visitHashSecret`。
- [ ] xingbuild Engineering 按共享合同实现自身正式站触发与同源接口。
- [ ] 完成两站正式域名写入、查询、设备排除和最终一致性公网验收。

本版本已完成提交、标签、推送和首次部署；后续人工验收发现固定 publish 重新发布纯静态 `dist` 会覆盖 Edge Functions，该发布链缺陷不回写本版本代码，由 v049.13.18 修复。
